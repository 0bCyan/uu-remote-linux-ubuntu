新增实验性 Linux 控制端 `uuremote-viewer`。/ Experimental Linux viewer `uuremote-viewer`.

### 新增 / Added
- **🧪 原生控制端 `uuremote-viewer`**（#36）：在 Linux 上用 UU 账号连接并控制其他设备——官方 Windows / Mac 被控端或本项目的 Linux 主机，
  也可凭对方的设备 ID 和验证码发起远程协助。包含启动窗口（设备列表）、桌面窗口（H.264 画面、键鼠、声音、文本剪贴板、只看模式）、
  文件传输、终端与终端会话列表、端口映射（只监听 127.0.0.1）、重启/关机。与主机 `uuremote-server` 相互独立，**主机行为不变**。
  - 使用：`uuremote-viewer login` 扫码登录，`uuremote-viewer ui` 打开启动窗口；命令行用法见 `uuremote-viewer --help` 和 README。
  - 运行依赖：GTK3、SDL2（Ubuntu/Debian `libsdl2-2.0-0`）、`ffmpeg` 命令；剪贴板需 `xclip`/`xsel` 或 `wl-clipboard`。
  - 与主机共用 `~/.config/uuremote/config.json`（`UU_CONFIG` 可另指定），因此不能用同一身份连接本机上的主机。
  - **已实测**：官方 Windows 被控端（画面、键鼠、文件列表与下载）、官方 Mac 被控端（画面）、本项目主机（画面、键鼠、文件、
    端口映射、终端；剪贴板、声音和远程协助在虚拟机中）。
  - ⚠️ **未实测**：重启/关机、终端会话列表的新建与接回、Wayland 下的窗口与剪贴板、多显示器；只解码 H.264 4:2:0。
    这是实验性功能，欢迎反馈问题。
  An experimental viewer/controller for UU Remote hosts; the host build and behaviour are unchanged. See the README for usage,
  dependencies and the tested scope (reboot/shutdown, terminal session list and Wayland are not tested live).
