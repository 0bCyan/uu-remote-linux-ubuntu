### 新增 / Added
- **预编译包内置 Wayland 与 GNOME/KDE 支持**（#43、#54）：Release 包新增 `libuu-wayland.so`（Hyprland / Sway / niri 等 wlroots）
  和 `libuu-portal.so`（GNOME / KDE Wayland）。程序按当前会话自动选择后端，只在 Wayland 会话里加载对应插件，X11 用户不需要任何
  Wayland 库。安装：
  ```sh
  install -Dm755 uuremote-server ~/.local/bin/uuremote-server
  install -Dm644 libuu-wayland.so libuu-portal.so -t ~/.local/lib/uu-remote-linux/
  ```
  系统要求：X11 与 wlroots 为 glibc ≥ 2.35；GNOME/KDE 插件为 glibc ≥ 2.39（Ubuntu 24.04、Fedora 40、Debian 13 及更新）及 libei ≥ 1.1。
  缺库或版本过旧时日志会写明原因。**验证范围**：插件加载、回退与报错在 Hyprland 虚拟机（ARM）实测，wlroots 采集正常；
  预编译的 GNOME/KDE 插件尚未在真机上完成画面/键鼠验收（引擎代码本身未改动）。Wayland 仍为实验性。
- The release now ships `libuu-wayland.so` and `libuu-portal.so`, loaded at runtime only on Wayland sessions; X11 hosts need no
  Wayland libraries. The portal plugin requires glibc >= 2.39 and libei >= 1.1. Plugin loading was tested on a Hyprland VM;
  the prebuilt GNOME/KDE plugin has not yet been accepted on real hardware.

### 改进 / Improved
- 在 GNOME/KDE Wayland 上缺少 portal 支持时，不再反复报看不懂的 `portal unavailable (code 2)`，而是直接说明原因和解决办法（#43）。
- README：支持表加入 niri（实验性，协议已按源码确认、未实机验收）；systemd 单元名须为 `uuremote-native.service`；uinput 无人值守授权示例（#55）。
