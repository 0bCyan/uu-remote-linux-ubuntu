### 主机端 / Host
- **手机自带输入法打字**（#13、#46）：官方 Windows 被控端用 `text_input` 动作接收手机输入法的文字。本版主机端支持这个动作，
  在 X11 上把文字（含中文）直接输入到当前窗口；不论它从哪个数据通道到达都会处理。
  ⚠️ 文字注入已在 X11 上实测（中英文、空格、回车均正确）；**手机端确实发送 `text_input` 是根据官方 Windows 被控端推断的，
  尚未用手机实测**。Wayland / 门户后端暂不支持，会记录一次警告。
  诊断：非 CONTROL 通道收到的输入动作会记录动作名（不含内容）。
- Mobile input-method text via the official `text_input {content}` action, typed on X11 (verified by injection; the mobile
  client sending it is inferred from the official Windows host, not yet confirmed with a phone).

### 控制端修复 / Viewer — fixed
- **控制端 → 官方 Windows 被控端剪贴板**：之前被控端确认收到，但粘贴为空。原因是控制端同时发送的「富剪贴板格式通告」
  会覆盖刚写入的文本，而 Windows 被控端之后从不请求数据。现在按被控端平台发送：Windows 及本项目主机只发文本变更，
  Mac 只发格式通告，平台未知时两者都发。已实测：Windows 被控端「运行」框可粘贴，官方 Mac 被控端正常。
  Viewer → official Windows host clipboard now works (verified live); Mac unchanged and verified.
