Wayland（GNOME / KDE portal）修复版本。X11 行为不变。
Wayland (GNOME / KDE portal) fix release. X11 behavior is unchanged.

### 修复 / Fixed
- **GNOME 开启分数缩放（如 125%、150%）时，鼠标点击偏到左上方**：portal 的绝对坐标被缩放了两次。现在 GNOME 直接使用画面坐标，
  KDE 保持原有逻辑；虚拟机内按钮级点击误差 ≤ 2 像素。
  GNOME with fractional scaling: absolute pointer positions were scaled twice, so clicks landed up-left of the target.
- **锁屏后重连时剪贴板失效**（portal）：剪贴板现在会等待 portal 会话恢复，并在锁屏状态的握手中保留已授权的剪贴板能力。
  Clipboard no longer gets disabled when a connection starts while GNOME is locked (portal).
- portal 键鼠注入失败时输出带数量上限的诊断日志（不记录按键内容）。/ Bounded diagnostics for portal input failures.
- 日志中记录房间令牌的剩余有效时间（只记录秒数）。/ Log the room token's remaining lifetime (seconds only).

### 已知问题 / Known issues
- Wayland（portal）下剪贴板目前只有「控制端 → Linux」方向可用，「Linux → 控制端」方向尚未通过验收。
  On the portal backend, clipboard works viewer → Linux only; Linux → viewer is not working yet.
- 长时间连接（约 20 分钟）可能被云端释放，原因仍在排查。/ Long sessions may be released by the cloud after ~20 min; under investigation.
- Wayland 支持仍为实验性，需从源码以 `--features wayland,portal` 编译。/ Wayland remains experimental (build from source).
