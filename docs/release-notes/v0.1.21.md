视频管线减少重复分配和过量编码。/ Fewer allocations and less wasted encoding in the video pipeline.

### 改进 / Improved（#20，感谢 @mengdehong）
- 采集到发送之间最多 4 帧在途：网络发不出去时采集端自动放慢，不再白白编码无法送出的帧。
  贡献者实验（发送受阻场景）：编码 CPU 耗时降低约 88%。
- 原生 Wayland 可选的 dma-buf 路径、Portal / KMS 路径复用采集缓冲；Portal 同一帧不重复复制。
- X11 进程内编码（`inproc-av`，需自行编译）缓存静态画面的采集与转色结果：静态画面每帧 CPU 降低约 40%。
- 原生 Wayland 关闭时完整释放协议对象。

⚠️ 以上性能数据来自贡献者在隔离 headless Sway / Xvfb 中的合成画面实验，未在维护者的真机上复测。
预编译的 X11 包默认走外部 FFmpeg 管线，受影响的主要是 Wayland / Portal / KMS / `inproc-av` 自编译用户。
Performance figures come from the contributor's headless Sway/Xvfb experiments; not re-measured on maintainer hardware.
