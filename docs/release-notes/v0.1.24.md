支持 Ubuntu 22.04 自带的 FFmpeg 4.4。/ Works with Ubuntu 22.04's FFmpeg 4.4.

### 改进 / Improved
- **自动适配 FFmpeg 版本**（#22，感谢 @Guancheng-Li）：启动编码前检测所用 FFmpeg 支持的参数。FFmpeg 5 及以上继续使用
  `-fps_mode vfr -enc_time_base 1/<fps>`；FFmpeg 4.x（如 Ubuntu 22.04）改用 `-vsync 0`。检测失败时保持新版参数。
  FFmpeg 4.x 下采集卡顿后的补帧会全部编码（新版会丢弃），属于已知降级。贡献者已在 FFmpeg 4.4.2 上验证。
  The host probes the FFmpeg it uses and falls back to `-vsync 0` only on FFmpeg 4.x; probe failures keep the modern arguments.

### 其他 / Other
- 新增几条只记结构的诊断日志（收到的 SOAC offer 结构、SDP 段落属性名、ice_id 是否一致），用于排查与官方控制端的互通，
  不记录 SDP 内容或任何 ID。
  Structure-only diagnostics for incoming offers (no SDP contents or ids).
