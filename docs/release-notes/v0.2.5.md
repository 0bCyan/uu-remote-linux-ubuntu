窗口颜色修复；控制端可接收官方 Mac 被控端的剪贴板。/ Window colors fixed; viewer receives the official Mac host's clipboard.

### 修复 / Fixed
- **深色系统主题下窗口文字看不见**（#43）：协助窗口、控制端启动窗口和工具窗口使用固定浅色背景，但部分文字跟随系统深色主题变成了白色。
  现在这些窗口固定使用浅色主题。已在虚拟机中设置深色偏好后截图确认。
  GTK windows now stay on the light theme, so text is readable under dark system themes.
- **控制端 ↔ 官方 Mac 被控端剪贴板**：Mac 被控端以 `public.utf8-plain-text`（UTF-8）提供文本，而不是 Windows 的 `CF_UNICODETEXT`，
  之前控制端不会请求，剪贴板始终不同步。现在两种格式都支持；主机端发给官方客户端的格式不变。
  Mac → 控制端已实机验证；⚠️ 控制端 → Mac 尚未验证。
  The viewer now handles the Mac host's UTF-8 text format (Mac → viewer verified live; viewer → Mac not yet verified).

### 已验证 / Verified with the official Mac host（FFmpeg 9.0.2）
- 画面 0 解码错误，键盘输入正确，文件上传/下载/列目录 sha256 一致。
