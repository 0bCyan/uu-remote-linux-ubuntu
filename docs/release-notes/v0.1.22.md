v0.1.21 视频管线改动的两处修正。/ Two follow-up fixes to the v0.1.21 video pipeline changes.

### 修复 / Fixed
- 原生 Wayland 的 dma-buf 映射失败、回退到 SHM 时，已缓存的 dma-buf 缓冲没有释放（最多两个槽位，到会话结束才回收）。
  Release cached dma-buf buffers when capture falls back to SHM.
- 原生 Wayland 在发送受阻（背压）解除后的第一帧可能是受阻前预取的旧画面；现在等待超过两个帧间隔时会重新采集。
  After a backpressure stall the first native Wayland frame is captured fresh instead of reusing the stale prefetch.

两处均由代码审查发现，只做了编译和单元测试，未在真机复现。
Both found in review; compile- and unit-tested only.
