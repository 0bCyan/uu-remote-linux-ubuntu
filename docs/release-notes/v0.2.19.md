无头 Wayland 出画面、自定义码率、`show` 与登录体验修复。/ Headless Wayland video, custom bitrate, `show` and login fixes.

### 修复 / Fixed
- **无头 Wayland 主机连上没有画面**（#64 / #65，感谢 @axlrose）：输出不支持 DPMS 时电源握手失败不再中断视频；贡献者在 sway headless 上复现并验证。
- **自定义码率单位错误**（#67，感谢 @JuanZoran）：手机端自定义码率按 bit/s 发送（1 Mbps = 1000000），此前被当成 kbit/s 而触发 100 Mbps 上限，
  导致大量重传、画面滞留。贡献者在 Hyprland + NVENC 上用手机实测。另外对明显是 Mbps / kbps 的小数值做了兜底换算（维护者补充，未实测）。
- **`uuremote-server show` 静默卡 30 秒**（#62，感谢 @axlrose）：服务被条件跳过、反复崩溃重启或启动失败时立即报出真实原因。贡献者已用真实 systemd 单元验证。
- **登录二维码反复立即失效**（#68，感谢 @axlrose）：状态轮询在服务器立即应答时不再紧循环（2 秒退避）；二维码连续在几秒内失效时指数退避，
  并提示可备份删除 `~/.config/uuremote/config.json` 重新登录（注册新设备身份，#68 中以此恢复）。退避逻辑未在被标记的设备上实测。

### 改进 / Improved
- `doctor`：会话里没有 `DISPLAY` / `WAYLAND_DISPLAY` 时给出提示（#66，感谢 @axlrose）。
- 文档：`inproc-av` / `viewer-ffmpeg` 只支持 FFmpeg 6.x，FFmpeg 7+ 会在依赖里报 `avfft.h file not found`（#63）。
