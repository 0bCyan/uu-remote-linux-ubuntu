### 控制端修复 / Viewer — fixed（均为实测发现并验证 / found and verified live）
- **官方 Windows 被控端上传文件**：之前上传会被拒绝（错误码 2）。现在按官方客户端的格式发送（Windows 路径、修改时间、压缩文件列表），
  64 KiB 与 1 MiB 文件上传后再下载回来 sha256 一致。下载也不再拒绝大于 32 KiB 的数据块（错误码 3）。
- **官方 Windows 被控端端口映射**：之前每个连接都超时；现在可正常转发（经被控端访问 HTTP 返回 200）。
- **官方 Windows 被控端终端**：之前连上后没有任何输出；现在可打开 PowerShell 并交互。
- **启动窗口**：设备列表每 30 秒刷新后，已打开的设备页按钮全部失效的问题；「断开当前连接」确认框改为中文按钮。
- **连接官方 Mac 被控端时键盘错位**（#39，感谢 @wanglz111，#40）：按 1 出空格、Backspace 出 c。Mac 目标改用 macOS 原生键码
  （按物理位置转发，PC 的 Win 键对应 Command），Windows 与本项目主机仍用 Windows VK；无法确定目标平台时拒绝控制而不是乱发键码。
  贡献者已在官方 Mac 被控端实机确认；⚠️ ISO/JIS 键盘、媒体键与 Mac 远程协助未验收。
- **FFmpeg 4.4 下没有画面**（#40）：v0.2.0 / v0.2.1 的控制端解码参数 `-fps_mode` 不被 FFmpeg 4.4（如 Ubuntu 22.04 自带版本）识别，
  解码进程直接退出。现改用新旧版本都支持的参数。
- 对本项目主机的上传、端口映射、终端新建/接回均已回归验证。
- Upload, port mapping and terminal now work with the official Windows host; launcher device page stays usable after list refreshes.
