修复未登录（访客）远程协助时 X11 没有画面。/ Fix missing video during guest remote assistance on X11.

### 修复 / Fixed
- **X11 访客远程协助无画面**：未登录账号、以访客身份开启远程协助时，设备初始化过程会临时打开再关闭一次屏幕采集，
  把正在使用的 X11 连接一起关掉，日志出现 `Live desktop stream stopped: X11 display wake failed`，控制端连上后一直黑屏。
  现在 X11 连接按引用计数管理，只有最后一个采集对象释放时才关闭；X11 分辨率变化后重建采集也不再有同样的隐患。
  已在虚拟机（Xvfb 虚拟桌面）上实测：访客协助加入、画面、鼠标移动/点击、键盘均正常。⚠️ 未用官方客户端在真机上复测。
  Guest assistance on X11 no longer loses the display connection; video, mouse and keyboard verified in a VM.
