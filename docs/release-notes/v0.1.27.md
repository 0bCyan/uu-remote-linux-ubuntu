GNOME Wayland 连接中切换缩放后的停帧修复。/ Recover from live scaling changes on GNOME Wayland.

### 修复 / Fixed
- **GNOME Wayland 连接中切换显示缩放后画面持续冻结**（#25、#26，感谢 @wanglz111）：已推流的 Portal 流若「暂停且没有有效格式」
  持续 5 秒，复用现有会话恢复；恢复时允许逻辑尺寸变化，仍校验采集帧尺寸。启动阶段和静态画面不会触发这个超时，
  等待授权与 D-Bus 的过程不再占用输入锁。
  ⚠️ 贡献者实测：Ubuntu 26.04 + GNOME Wayland、单屏 3840×2160，连接中 200%→166.67%→200% 恢复后画面和全屏鼠标正常；
  **切换时会短暂停顿、黑屏后恢复，并非无缝；5 秒是判定阈值，不是总恢复时间**。物理分辨率变化、多屏、锁屏恢复未实机验证。
  Portal recovers after a live scale change (brief freeze/black, not seamless); physical resolution changes remain unsupported.
- Portal 失效检查出错时只记日志，不再让主机主循环退出。/ A failed Portal staleness check no longer ends the host loop.
