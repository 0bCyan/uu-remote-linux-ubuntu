Wayland（GNOME / KDE portal）修复版本。X11 行为不变。
Wayland (GNOME / KDE portal) fix release. X11 behavior is unchanged.

### 修复 / Fixed
- **GNOME Wayland 首次连接黑屏，桌面重绘后才恢复**（#2）：新建的 portal 会话会把第一帧有效画面当作锁屏残留清掉，
  静止的桌面又不会产生新帧，所以画面一直是黑的。现在只有真正检测到锁屏（或 portal 被关闭）时才丢弃旧画面。
  First connection on GNOME Wayland stayed black until the desktop redrew (#2): a fresh portal session discarded its
  first valid frame as if it came from the lock screen.

### 其他 / Other
- CI 新增 `--features wayland,portal` 的编译和测试。/ CI now builds and tests `--features wayland,portal`.

### 已知问题 / Known issues
- Wayland（portal）下 Mac 控制端输入的下划线可能丢失（#3，正在排查，与键盘布局有关）。
- Wayland 下剪贴板只有「控制端 → Linux」方向可用；长连接约 20 分钟可能被云端释放（排查中）。
- Wayland 支持仍为实验性，需从源码以 `--features wayland,portal` 编译。
