### 新功能 / Added
- **H.265**：控制端和主机都支持时自动使用 H.265，同等画质下码率更低。与官方主机一致，由主机按双方能力选择编码
  （官方 Mac 客户端没有手动切换编码的菜单）。连接时主机会告知客户端自己能编哪些格式（CodecNegotiation）。
  支持 `hevc_nvenc`、`libx265` 和显式 VAAPI 的 `hevc_vaapi`；硬件失败先回落软件 HEVC，再回落 H.264。
  需要时用 `UU_VIDEO_CODEC=h264` 强制使用 H.264。
- 真彩（4:4:4）同样适用于 H.265（hevc_nvenc `rext` / libx265 `main444-8`）。
  ✅ 已用官方 Mac 客户端在 RTX 3090（hevc_nvenc，含 4:4:4）实机验收：画面正常、重连正常、无丢帧。
  ⚠️ libx265、hevc_vaapi、Windows/手机客户端尚未实机验证；如有问题请设置 `UU_VIDEO_CODEC=h264` 并提 issue。
  The host now uses H.265 when both sides support it (the host picks the codec, like the official host), announces
  its encoders with CodecNegotiation, and falls back to software HEVC, then H.264. `UU_VIDEO_CODEC=h264` forces H.264.
  Verified with the official Mac viewer on NVENC including 4:4:4; other encoders and viewers are unverified.
