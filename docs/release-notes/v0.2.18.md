### 新增 / Added
- **`.deb` 安装包**（amd64 / arm64）：`sudo apt install ./uu-remote-linux_0.2.18_amd64.deb` 一步装好程序、两个桌面插件、
  用户级 systemd 服务和应用菜单图标，依赖由 apt 自动安装。之后以桌面用户运行：
  ```sh
  uuremote-server login
  systemctl --user enable --now uuremote-native.service
  ```
  服务随图形会话启动（GNOME / KDE 会自动传入显示环境；Xfce 等需按 README 补 `DISPLAY`）。uinput 权限不会自动开启，规则文件放在
  `/usr/share/doc/uu-remote-linux/`。安装流程在 CI 的 Ubuntu 22.04 上实测（apt 安装、`--help`、systemd 单元校验）；尚未在真实桌面上完整验收。
- **远程开机辅助（实验性，默认关闭，`UU_WOL_HELPER=1`）**：仿照官方 Windows 被控端，登录后向网易上报本机局域网信息，
  收到云端的唤醒请求时向同一局域网发送唤醒包，让这台常开的 Linux（例如 NAS）帮你唤醒同局域网的其他电脑。
  字段名来自官方程序的日志字符串，**未经端到端验证**；不开启时不上报任何局域网信息，只记录唤醒推送的字段名（不含 MAC/IP）。
- Debian packages (amd64/arm64) with the binaries, plugins, a systemd user unit and menu entries; install-tested on Ubuntu 22.04 in CI.
  Experimental, opt-in Wake-on-LAN helper (`UU_WOL_HELPER=1`) modelled on the official Windows host; not verified end to end.

### 修复 / Fixed
- `uuremote-server doctor` 不再输出带完整路径的插件加载日志（路径可能含用户名）。
