修复连接断开或重启后鼠标/按键卡住，Hyprland 截屏改为流水线。/ Fixes stuck mouse buttons/keys after disconnects or restarts; pipelined Hyprland capture.

### 修复 / Fixed
- **鼠标键或按键卡在按下状态，导致之后点击全部无效**：如果远程连接在按住鼠标或按键时断开，或者服务重启，按下状态可能残留，
  之后的点击和输入都会出错。现在桌面连接建立、断开以及服务启动/退出时，会自动松开所有按住的键和鼠标键
  （X11 松开显示器上所有按下的键；uinput 重置本服务的虚拟设备；Wayland/portal 松开本服务能发送的所有键）。
  旧连接迟到的事件不会影响新连接；文件传输、终端、端口映射这些工具连接不会触发松键。
  ✅ X11 实机（官方 Mac 控制端，按住鼠标时关闭远控窗口后重连）和虚拟机验收通过；portal 只做了编译和单元测试。
  Input is released at desktop session boundaries and at service start/stop. Verified on X11 hardware; portal unit-tested only.
  注意：X11 下会同时松开本机键盘上正在按住的键。/ On X11 this also releases keys held on the local keyboard.

### 改进 / Improved
- **Hyprland 原生后端（`--features wayland`）**：截屏改为双缓冲流水线，控制端选择的帧率会同步到截屏和编码
  （#9）。可选 `UU_WAYLAND_DMABUF=1` 尝试 dma-buf 映射（默认关闭，只支持线性缓冲，失败回退 shm）；`UU_WAYLAND_PIPELINE=0` 关闭流水线。
  ⚠️ 只在虚拟机里测量过，实机帧率提升尚未验证，实际帧率仍受合成器限制。发布包（X11 版）不含此功能。
  Pipelined screencopy and viewer-selected fps for the native Wayland backend (VM-measured only).
- **AMD VAAPI**：#9 的报告者在 AMD Phoenix 上实测 v0.1.7 的 `UU_VIDEO_ENCODER=vaapi` 有效，消除了高分辨率下的顿挫感。
  AMD VAAPI confirmed by a user on AMD Phoenix.
- 无人登录的虚拟桌面（`contrib/virtual-desktop`）在虚拟机里用官方 Mac 控制端验收了画面、键鼠、剪贴板（虚拟机→Mac）、
  静音运行的声音和会话结束后的恢复。/ Linger virtual desktop accepted in a VM with the official Mac viewer.
