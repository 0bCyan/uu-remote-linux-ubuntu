测量工具：`desktop-video-probe` 可选码率档。/ Probe bitrate presets.

### 新增 / Added
- `desktop-video-probe` 支持 `UU_PROBE_QUALITY=1..5`，对应控制端画质档（1 极速 1M、2 流畅 2M、3 高清 8M、4 蓝光 20M、5 自动）。
  码率档走平均码率（ABR）路径，便于不用控制端复测 #15 的灰屏修复（#9 的建议）。
  `desktop-video-probe` accepts `UU_PROBE_QUALITY=1..5` (viewer bitrate presets; 5 = Auto/CRF).
