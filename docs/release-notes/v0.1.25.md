GNOME Wayland 缩放下的鼠标修复。/ Pointer fix for scaled GNOME Wayland desktops.

### 修复 / Fixed
- **GNOME Wayland 开启桌面缩放后，远程鼠标只能控制左上部分**（#23、#24，感谢 @wanglz111）：Portal 后端在同一授权会话里
  改用 EIS 输入，按 `mapping_id` 匹配屏幕区域，并按实际帧尺寸映射坐标；缺少映射信息或 Portal 不支持 EIS 时保留原路径。
  日志不记录输入内容。X11、原生 wlroots 和 uinput 路径不变。
  ⚠️ 贡献者在此前的迭代上实测过 Ubuntu 26.04 / GNOME 50、单屏 4K、200% 缩放；最终提交、其他缩放比例、锁屏恢复、
  断线重连和多屏尚未实机验证。
  Portal input uses EIS regions mapped to the captured frame; the final commit and other scales are not yet hardware-verified.

### 构建 / Build
- `--features wayland,portal` 现在需要 `libei >= 1.1` 开发包（Debian/Ubuntu：`libei-dev`）。预编译的 X11 包不受影响。
  Portal builds now require libei >= 1.1.
