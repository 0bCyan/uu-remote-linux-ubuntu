Hyprland 双屏点击偏移修复，并可在手机端切换显示器（实验性）。/ Hyprland dual-monitor pointer fix and opt-in monitor switching.

### 修复 / Fixed
- **Hyprland 双屏点击偏移**（#57，感谢 @JuanZoran）：原生 Wayland 后端的绝对鼠标定位改为绑定正在采集的输出
  （此前 uinput 绝对坐标映射到整个桌面，双屏时点击位置偏移）。uinput 仍用于键盘、按键和相对移动。
  **影响所有 Hyprland 用户的默认路径**；单屏下映射结果与之前等价。贡献者已在双屏真机（2560×1440@125% + 1920×1080@133%）
  上验证落点误差 ≤ 2 像素；维护者未另行复测。
- Absolute pointer motion on the native Wayland backend is now bound to the captured output (it previously spanned the whole
  desktop through uinput, offsetting clicks on multi-monitor setups). Verified by the contributor on real dual-monitor hardware.

### 新增 / Added
- **Hyprland 多显示器切换（实验性，默认关闭）**：设置 `UU_WAYLAND_MULTISCREEN=1` 后，手机端可以选择物理显示器，画面与
  鼠标定位同步切换；`UU_WAYLAND_OUTPUT` 指定默认屏幕。通过 `hyprctl` 枚举未旋转的显示器，插拔或布局变化后需重启服务；
  切换失败会恢复原屏。由贡献者用官方手机客户端在 Omarchy / Hyprland 双屏上实测。
- Opt-in Hyprland monitor switching (`UU_WAYLAND_MULTISCREEN=1`), accepted by the contributor with the official phone client.
