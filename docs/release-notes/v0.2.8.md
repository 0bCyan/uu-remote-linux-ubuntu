群晖 / NAS 容器镜像。/ Docker image for Synology and other NAS boxes.

### 新增 / Added
- **群晖 / NAS（Docker，无桌面）**：`ghcr.io/vallierdev/uu-remote-linux`，在没有图形界面的 NAS 上运行本项目主机，
  供官方客户端使用文件传输、终端（容器内 bash）和端口映射（经 UU 访问家里局域网的服务）。不提供远程桌面。
  已在群晖 DSM 7.3.2（x86_64）上实测：文件上传下载 sha256 一致、终端回显正常、端口映射访问 DSM 管理页返回 200。
  安装与首次扫码登录见 [docker/README.md](https://github.com/VallierDev/uu-remote-linux/blob/main/docker/README.md)。
- Headless NAS container image (file transfer, terminal, port mapping), verified on Synology DSM 7.3.2 (x86_64).

主机端与控制端程序与 v0.2.7 相同。/ Host and viewer binaries are unchanged from v0.2.7.
