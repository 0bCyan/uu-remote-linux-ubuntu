Wayland（wlroots）手机输入法上屏；登录默认直连，不走环境代理。/ Mobile IME text on wlroots Wayland; cloud API ignores ambient proxies by default.

### 新增 / Added
- **wlroots Wayland 支持手机输入法 `text_input`**（#51，感谢 @hiclaw）：手机端输入法提交的文字，
  在 Hyprland / Sway 等 wlroots 合成器上通过虚拟键盘的备用键码上屏。仅在 Hyprland 0.56.2 上实测；
  KWin / GNOME（门户后端）仍不支持，见 #50。
- Mobile IME `text_input` now types through the virtual keyboard's spare keycodes on wlroots compositors.
  Tested on Hyprland 0.56.2 only; KWin/GNOME (portal backend) are not covered yet.

### 变更 / Changed
- **云端接口默认忽略代理环境变量**（#52，感谢 @aresbit）：本地有拦截 TLS 的 HTTP/SOCKS 代理时，登录会报
  `tls handshake eof`。现在主机和控制端访问网易服务器默认直连，忽略 `http_proxy` / `https_proxy` / `all_proxy`；
  确实需要经代理上网的环境请设置 `UU_USE_PROXY=1`。未在拦截代理环境中实机验证，CI 测试通过。
- Cloud API clients now bypass `http_proxy` / `https_proxy` / `all_proxy` by default; set `UU_USE_PROXY=1` if your
  network requires a proxy. Not verified against an intercepting proxy; CI passes.
