大目录文件传输修复、上报实际刷新率、NVENC 省掉 CPU 颜色转换。/ Large-folder file transfer fix, real refresh rate, NVENC without CPU color conversion.

### 修复 / Fixed
- **文件传输打开文件很多的目录时一直转圈**：目录回复同时带了未压缩和压缩两份列表，几千个文件时超过数据通道单条消息上限，
  回复被丢弃。现在压缩列表始终发送，未压缩副本只在放得下时附带；同时把 SCTP 发送上限从 64 KB 提到 256 KB
  （与官方控制端在 SDP 中声明的一致）。已在 5600 个文件的目录上实测。
  Large directory listings no longer exceed the data-channel message limit (verified with 5600 entries).

### 改进 / Improved
- **上报显示器实际刷新率**（#16）：`display_info`、能力通知和编解码协商原先固定报 60，现在取当前显示模式
  （Hyprland 用 `hyprctl`，X11 用 `xrandr`；取不到时仍为 60，`UU_DISPLAY_FPS` 可手动指定）。
  The host reports the monitor's refresh rate instead of a fixed 60 (`UU_DISPLAY_FPS` overrides).
- **NVENC 直接接收 BGRA/BGR0**（#16）：4:2:0 且不缩放时，颜色转换交给 GPU，省掉 FFmpeg 子进程里的 CPU 转换；
  色彩标记与原来一致（BT.601 有限范围）。`UU_NVENC_RGB=0` 可恢复原路径。
  ⚠️ 已在 X11 + RTX 3090 上实测画面与颜色；Hyprland 4K 高帧率下的 CPU/帧率收益尚未实测。
  NVENC converts RGB on the GPU; verified on X11, the Hyprland 4K gain is not yet measured.
