修复 iPhone 上「超清 / 原画」「常规 / 真彩」点不动。/ Fix iPhone quality and chroma choices being locked.

### 修复 / Fixed
- **iPhone 无法切换画质与真彩**（#49，感谢 @RiverOnVenus 的细致排查）：连接本项目主机时，iPhone 的「超清」「原画」
  以及「常规 / 真彩」按钮点了没反应，只有帧率能改。原因是主机发出的设备能力消息（`forward_setting` 的 `device_capability`）
  格式与官方 Windows 被控端不一致，iPhone 无法识别，于是锁定在默认值。现在按官方格式发送设备能力（含 4:4:4 等真实支持的格式），
  并补发发送参数 `sender_para_info`。
  已实测：iPhone（UU 远程 4.42.0）连接修复后的主机，可以切换画质（主机收到新的画质请求）。Mac 客户端不依赖这条消息，此前即正常。
- Device capability is now sent in the official nested shape (and `sender_para_info` is added), so the iPhone client unlocks
  quality and chroma choices. Verified with the UU iPhone app 4.42.0.

### 其他 / Other
- 控制端窗口与主机使用同一图标，并新增控制端启动项 `contrib/desktop/uu-remote-linux-viewer.desktop`（#13）。
