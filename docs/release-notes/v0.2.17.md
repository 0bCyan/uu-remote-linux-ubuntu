新增 `uuremote-server doctor` 一键诊断。/ New `uuremote-server doctor` diagnostic report.

### 新增 / Added
- **`uuremote-server doctor`**：一次输出提 issue 需要的状态——会话类型与桌面、最终选中的后端（含「Wayland 会话里用了 X11 后端会黑屏」的提醒）、
  Wayland / portal 插件能否加载及缺什么库、`/dev/uinput` 与显卡 render 节点权限、FFmpeg 可用编码器和版本、默认编码（H.264 / H.265）、
  是否已登录、服务状态和重复进程。只输出布尔值、名称和版本，主目录和用户名会被替换，不含账号 ID、令牌、IP、MAC 或文件内容，
  可以直接贴到 issue。issue 模板已改为先运行它。
- `uuremote-server doctor` prints a paste-safe report (session, backend, plugins, permissions, encoders, default codec, sign-in and
  service state) with no ids, tokens, addresses or file contents.
