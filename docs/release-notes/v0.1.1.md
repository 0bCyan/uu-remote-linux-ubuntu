### 修复 / Fixed
- 传入无法识别的参数（例如手误或 `--version`）时，程序不再在已运行的服务旁边再启动一个完整的被控端，
  而是打印用法并以退出码 2 结束；`help` / `-h` / `--help` 显示用法。
  An unrecognized argument (a typo, `--version`, ...) no longer starts a second full host next to the running
  service; it prints usage and exits with code 2. `help` / `-h` / `--help` print usage.
