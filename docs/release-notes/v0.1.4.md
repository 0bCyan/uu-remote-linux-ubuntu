新增端口映射。/ Adds port mapping.

### 新增 / Added
- **端口映射**：支持官方客户端的「端口映射」工具。在控制端添加规则（本地端口 → 目标地址:端口），即可把控制端本地端口转发到
  Linux 被控端能访问到的地址，例如 `127.0.0.1:22`（SSH）或局域网里的其他服务。上传、下载、多连接并发均已用官方 Mac 客户端验收。
  设置 `UU_PORT_MAPPING=0` 可关闭。
  **Port mapping**: the official "port mapping" tool now works — forward a local port on the viewer to any address reachable
  from the Linux host (e.g. `127.0.0.1:22`). Upload, download and concurrent streams verified with the official Mac client.
  `UU_PORT_MAPPING=0` disables it.

### 修复 / Fixed
- 数据通道单条消息上限从 64 KB 提升到 256 KB（与官方被控端一致）。此前控制端发送的大于 64 KB 的消息会被拒发，导致上传卡住。
  Data-channel messages up to 256 KB are now accepted (as the official host advertises); larger viewer messages were refused before.
- 画质/帧率/分辨率切换时，旧编码器的帧可能插到新编码器的关键帧之后，导致画面花屏（#5，感谢 @BLACKIELF）。
  Encoder restart ordering on quality/fps/resolution changes (#5, thanks @BLACKIELF).

### 其他 / Other
- 可选的进程内编码（`--features inproc-av`，默认关闭；Release 安装包不受影响）（#6，感谢 @ferstar）。
  Optional in-process encoding (`--features inproc-av`, off by default) (#6, thanks @ferstar).

### 已知问题 / Known issues
- 控制端不支持 TCP 半关闭（发送方关闭写方向后会直接关闭整条连接）；SSH、HTTP 等常见协议不受影响。
  The viewer does not support TCP half-close; common protocols such as SSH and HTTP are unaffected.
- Wayland 仍为实验性；portal 下「Linux → 控制端」剪贴板和约 20 分钟后的云端断开仍在排查。
