无头服务器、虚拟桌面、uinput 输入和终端快捷键。/ Headless servers, virtual desktop, uinput input and terminal shortcuts.

### 新增 / Added
- **无头模式** `UU_DESKTOP_BACKEND=none`：没有显示器、没有图形会话也能上线，提供终端、文件传输和端口映射。
  配合 `loginctl enable-linger` 可以开机自动上线。已在实机上用官方 Mac 客户端验收（端口映射传输 10 MB 校验一致）。
  Headless mode: online without a display; terminal, file transfer and port mapping verified with the official Mac viewer.
- **虚拟桌面** `contrib/virtual-desktop/`：用 Xvfb 创建虚拟屏幕并启动桌面会话，没有显示器的服务器也能使用完整的远程桌面。
  实机验收了画面和键鼠；默认的「用户总线」模式（把 `DISPLAY` 导入 systemd 用户会话）尚未在纯无头机器上验证。
  Virtual desktop scripts (Xvfb + session). Video and input verified; the default user-bus mode is not yet verified on a
  truly monitorless machine.
- **uinput 虚拟键鼠**（参考 Sunshine）：Wayland/portal 下，只要当前用户能访问 `/dev/uinput`（README 里有一条 udev 规则），
  就自动改用内核级虚拟键盘和鼠标，发送物理按键码，不依赖键盘布局，也不需要 portal 输入授权。应能解决 #3（下划线被吞）。
  `UU_INPUT_BACKEND=auto|uinput|native`；X11 继续默认用 XTest。
  uinput keyboard/mouse on Wayland (layout independent, no portal input consent); should fix #3.
- **终端快捷键**：Mac 控制端的 Cmd 和 Ctrl 到被控端都是 Ctrl。焦点在终端窗口时，Ctrl+V / Cmd+V 自动转成 Ctrl+Shift+V 粘贴；
  Ctrl+C 始终是中断，复制用 Cmd+Shift+C（X11，`UU_TERMINAL_SHORTCUTS=0` 关闭）。
  Terminal-aware paste: Ctrl+V/Cmd+V paste in terminal windows, Ctrl+C always interrupts.

### 修复 / Fixed
- 没有桌面时（无头模式，或 portal 后端还没授权时）打开端口映射会被控制端立即断开：现在工具连接会收到屏幕信息和「允许」权限。
  Port mapping was aborted by the viewer when no desktop was available.
- 明确设置的 `DISPLAY` 打不开时，不再悄悄改用 `:0`/`:1`（会截到真实屏幕），而是报错。
  An explicit DISPLAY that cannot be opened no longer falls back to the physical screen.
