控制端补测：重启/关机、终端会话列表、Wayland；主机远程关机不再等待授权弹窗。/ Viewer power, terminal list and Wayland tested; host power actions never wait for a polkit prompt.

### 修复 / Fixed
- **远程重启/关机不再卡在授权弹窗**：被控端用户没有 polkit 权限时（例如本机没有活动的图形会话），`systemctl reboot/poweroff`
  会一直等待，并可能在被控端屏幕上弹出密码框。现在加了 `--no-ask-password`，没有权限时直接失败并在日志记录 `ok=false`。
  正常情况下（本机有活动的图形会话）行为不变。
  Reboot/shutdown no longer wait for a polkit authentication dialog on the host; without permission they fail and are logged.

### 控制端实测补充 / Viewer testing
在虚拟机中用第二个主机身份实测通过（`uuremote-viewer` 连接本项目主机）：
- 远程**重启**、**关机**，以及关机后重新开机上线。
- 终端会话列表：新建、双击接回（重放历史输出、原 shell 环境保留）、确认后结束会话。
- Wayland（Hyprland）下的桌面窗口与剪贴板（`wl-copy`/`wl-paste`，双向）。
⚠️ 仍未实测：GNOME/KDE Wayland 下的窗口与剪贴板、H.265 与 4:4:4（只解码 H.264 4:2:0）、多显示器。
Tested in a VM: reboot, shutdown and power-on, terminal session list, Wayland (Hyprland) window and clipboard.
