### 新增 / Added
- **`desktop-video-probe` 支持固定输入**（#9，感谢 @hiclaw 的建议）：设置 `UU_PROBE_INPUT=<视频或图片序列>`（如 `clip.y4m`、
  `clip.mp4`、`frames/%05d.png`）时不采集桌面，而是用与生产会话相同的 FFmpeg 编码参数（编码器、码率档、GOP、色度、缩放）
  编码该输入，消除桌面内容对测量的影响；`UU_PROBE_LOOP=1` 循环输入直到 `UU_PROBE_FRAMES`。输入打不开或帧数不足时非零退出。
  正常会话路径不变。已用 Y4M、MP4、PNG 序列验证，重复运行输出逐字节一致。⚠️ NVENC/VAAPI 下的固定输入未实机验证。
  `desktop-video-probe` can encode a fixed input (`UU_PROBE_INPUT`) with the production encoder arguments.
