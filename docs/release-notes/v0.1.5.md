### 修复 / Fixed
- **远控约 20 分钟后被云端断开**：官方客户端会定期（约每 5 分钟）通过信令刷新房间的重连凭证（`refresh_reconnect_key`），
  之前没有实现，云端大约 20 分钟后就会回收房间并断开连接。现在被控端会按官方节奏刷新；凭证只保存在内存中，不写日志。
  在测试虚拟机里长连接稳定运行 44 分钟以上（已越过原来的断开点），在 X11 实机上确认刷新被云端接受。
  Sessions were released by the cloud after ~20 minutes because the room's reconnect key was never refreshed. The host now
  refreshes it like the official clients (~every 5 minutes); the key stays in memory and is never logged.
- 旧的信令连接在重连后会被正确关闭。/ Stale signaling connections are closed after a reconnect.

  Two-way clipboard on the portal backend passes in the VM; the official Mac viewer only accepts the host clipboard while the
  remote window has focus.
