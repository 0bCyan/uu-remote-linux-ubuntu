### 新增 / Added
- **Mac 快捷键**：在 Mac 远控窗口菜单里**关闭「使用 macOS 快捷键」**后：
  - Cmd+C / V / A / F / X / Z 是复制、粘贴、全选、查找、剪切、撤销（Cmd+Shift+Z 等组合同样可用）；
  - 在终端里 Cmd+C / Cmd+V 自动变成终端的复制、粘贴（Ctrl+Shift+C / V），**Ctrl+C 始终是中断**；
  - 其他 Cmd 组合键和单独按 Cmd 仍然是 Super（Windows 键）。
  只对 Mac 控制端生效（按连接请求里的控制端平台判断），Windows 和手机控制端不受影响。✅ 已用官方 Mac 客户端在 X11 实机验收。
  保持该选项开启时行为和以前一样（客户端会把 Cmd 当成 Ctrl 发送）。
  With 「使用 macOS 快捷键」 off, Cmd shortcuts behave as on a Mac (terminal-aware copy/paste), only for macOS viewers.
