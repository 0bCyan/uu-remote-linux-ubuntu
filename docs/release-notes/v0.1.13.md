### 新增 / Added
- **托盘图标**：后台运行时，顶栏/任务栏会显示托盘图标，菜单里有「打开主窗口」、「允许他人远程协助」（与主窗口开关同步）和「退出」。
  - GNOME 通过 AppIndicator 显示（Ubuntu 自带扩展；运行时加载 libayatana-appindicator，无需额外编译依赖）；Xfce / Cinnamon / KDE 等使用系统托盘。
  - 「退出」会停止 `uuremote-native.service`（不会被自动重启）；之后从应用菜单「UU 远程 Linux 主机」打开，会重新启动服务并显示主窗口。
  ✅ Ubuntu 24.04 GNOME（X11）实机验收：图标、菜单、开关同步、退出、从应用菜单重新启动。⚠️ Xfce 等系统托盘路径尚未实机验收。
  Tray icon with open / allow / quit; Quit stops the user service and the launcher restarts it. Verified on Ubuntu GNOME.

### 改进 / Improved
- `uuremote-server show`：主机没在运行时，优先启动已安装的 `uuremote-native.service`，而不是另起一个不受管理的进程。
- 修复启动时的一个时序问题：先注册窗口唤起信号再写入 PID 文件，避免过早的 `show` 意外结束主机进程。
