首个公开版本。用官方 UU 远程客户端（Mac / Windows / 手机）远程控制 Linux 桌面。
First public release: control a Linux desktop from the official UU Remote clients.

**非官方项目，与网易无关。** / **Unofficial, not affiliated with NetEase.**

### 支持 / Supported
- X11 桌面（GNOME on Ubuntu 24.04 实机长期使用；KDE、Xfce、Cinnamon/MATE 虚拟机测试）
- 远程桌面（NVENC / libx264）、键鼠、指针样式、剪贴板、文件传输、终端、声音
- 画质 / 帧率 / 分辨率切换，锁屏状态与自动解锁，远程结束后自动锁屏，被控端静音运行，系统操作
- Wayland（Hyprland、GNOME/KDE portal）为实验性功能，需要从源码以 `--features wayland` / `--features wayland,portal` 编译

### 下载 / Download
`uu-remote-linux-v0.1.0-x86_64-linux.tar.gz`：X11 版可执行文件（x86_64，glibc ≥ 2.35，例如 Ubuntu 22.04+）。
运行时需要 `ffmpeg`、GTK 3（登录窗口）和 X11 相关库。安装和登录步骤见 README。

尚未实现的功能见 README「尚未实现 / 不支持」。欢迎提交 issue。
