修复 iOS 和 Windows 客户端无法打开终端。/ Fixes the terminal for iOS and Windows viewers.

### 修复 / Fixed
- **iOS 和 Windows 客户端打开终端失败**（#12，感谢 @cnetst）：iOS 提示「创建失败」，Windows 提示「连接已断开」。
  终端协议的应答和官方实现不一致：会话列表改为直接返回数组并保留请求编号；客户端指定会话编号时沿用该编号；
  「打开成功」的应答保证先于终端输出发送。
  ✅ 实机验收：官方 iOS 和 Mac 客户端都能正常创建终端、执行命令，后连接的客户端能看到并接着使用已有的终端会话。
  Terminal replies now match the official host (bare-array session list, client session ids, OPEN_RESP first).
  Verified with the official iOS and Mac viewers.

### 说明 / Note
- 同一时间只能有一台控制设备连接同一个被控端：另一台设备连上时，先连接的会被云端断开，这是网易 UU 的服务端行为，与官方被控端一致。
  The UU cloud allows one controlling device at a time; a new controller disconnects the previous one (official behavior).
