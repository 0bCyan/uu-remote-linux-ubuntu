### 主机端诊断 / Host diagnostics（#46）
- 收到不认识的输入事件时记一条日志（只有动作名和字段名，**不含输入内容**），用于排查手机输入法打字无反应。
- 小键盘按键记录被控端当前的 NumLock 状态（只记开/关，不记按键），用于排查小键盘不出数字。
- Logs unsupported input actions (names only, never typed text) and the server's NumLock state for numpad keys.
