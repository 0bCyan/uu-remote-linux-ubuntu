ARM64 预编译包；无硬件编码器时默认 H.264。/ aarch64 release package; CPU-only hosts default to H.264.

### 新增 / Added
- **aarch64 预编译包**（#59，感谢 @DeliciousBuding）：新增 `uu-remote-linux-v0.2.15-aarch64-linux.tar.gz`，与 x86_64 包相同，
  含 `uuremote-server`、`uuremote-viewer` 和两个桌面引擎插件；ARM64 主机不再需要源码编译。CI 新增 ARM64 原生构建与测试（#58）。
  aarch64 包由 GitHub ARM runner 构建，尚未在真实 ARM 主机上运行验收。
- New aarch64 release package (same contents as x86_64), built on GitHub ARM runners; not yet run on real ARM hardware.

### 变更 / Changed
- **只有 CPU 编码时默认使用 H.264**（#59）：libx265 比 libx264 慢约 10 倍（4 核 Ampere A1 上 1080p 约 15 帧对 155 帧），
  原先 CPU 主机默认 H.265 会掉到十几帧。现在只有使用硬件编码器（NVENC / 显式 VAAPI）时才自动选 H.265；
  `UU_VIDEO_CODEC=h265` 仍可强制 H.265。NVENC / VAAPI 主机行为不变。
- Without NVENC/VAAPI the host now picks H.264 even when both sides offer H.265; `UU_VIDEO_CODEC=h265` forces H.265.
