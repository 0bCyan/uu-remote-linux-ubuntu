### 修复 / Fixed
- **企业代理 / 自定义 CA 环境下登录失败**（#21，感谢 @liuji10000qian-svg）：除内置根证书外，现在也信任系统证书库，
  并遵循 `SSL_CERT_FILE` / `SSL_CERT_DIR`。会做 TLS 拦截的代理（使用自签 CA）此前会导致设备注册请求失败。
  Trust the system certificate store and honor `SSL_CERT_FILE` / `SSL_CERT_DIR` in addition to the bundled roots.
- **网络请求失败时只显示「error sending request」**：错误信息现在包含底层原因链（证书、代理、DNS、超时等），
  并去掉 URL 中的用户名密码（如代理凭据）和查询参数。
  Transport errors now include their cause chain, with URL credentials and query strings removed.

⚠️ 自定义 CA / 代理环境未实测，请在 #21 反馈新版本的错误信息。
